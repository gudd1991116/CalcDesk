# CalcDesk for Android

离线版 [calcdesk.app](https://calcdesk.app) 工具箱：日期时间、单位换算、数学、开发与生活实用工具。

- **UI**：Jetpack Compose + Material 3（青绿品牌色）
- **导航**：带 fade / slide 的平滑转场
- **隐私**：无 INTERNET 权限，本地计算，无广告 SDK（v1）
- **上架说明**：见 [PLAY_STORE.md](./PLAY_STORE.md)

## 打开工程

用 **Android Studio** 打开目录：

`C:\Users\GDD\Documents\androidProject\AndroidWorkspace\CalcDesk`

## 运行

```bat
gradlew.bat :app:assembleDebug
```

安装 `app\build\outputs\apk\debug\app-debug.apk` 到设备，或在 Android Studio 直接 Run。

`com.qiyuan.calcdesk`
